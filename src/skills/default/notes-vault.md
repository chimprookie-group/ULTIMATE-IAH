# Notes Vault

1. Cherche une note existante avant d'en créer une.
2. Utilise des titres explicites et des wikilinks `[[Titre]]`.
3. Ajoute des tags cohérents sans proliférer.
4. Relie une nouvelle décision à la note de projet concernée.
5. Utilise l'action `graph` pour inspecter les liens et les orphelins.
6. Ne supprime une note qu'après confirmation explicite.

Les notes sont stockées dans le vault local et indexées pour la recherche.
