# Test First

## Boucle

1. Reproduis le bug ou écris le comportement attendu dans un test ciblé.
2. Lance le test et vérifie qu'il échoue pour la bonne raison.
3. Applique le plus petit correctif.
4. Relance le test ciblé, puis la suite complète.
5. Lis l'erreur réelle ; ne devine pas.
6. Garde le test comme régression.

## Preuve

Rapporte la commande exacte, le nombre de tests et le résultat. Si le test ne
peut pas être exécuté, dis-le et explique pourquoi.
