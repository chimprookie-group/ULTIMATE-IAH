# Notes — vault Markdown

Notes est le vault Markdown natif d’Ultimate IAH. Les fichiers restent lisibles
par n’importe quel éditeur ; SQLite ne sert que d’index.

## Stockage

- Vault : `~/.local/share/Crasy/deepcrasy-h/vault`.
- Index : `vault/.ultimate-iai/notes.db`.
- Corbeille : `vault/.ultimate-iai/trash`.
- Images : `vault/assets`.
- Override : variable `ULTIMATE_IAH_VAULT`.

## Fonctions

- création, édition, autosauvegarde, aperçu Markdown ;
- recherche, tags, épinglage, renommage et corbeille ;
- wikilinks `[[Titre]]`, backlinks et graphe ;
- note quotidienne ;
- pièces jointes image ;
- outils agent `ultimate_notes`.

## Raccourci

**Ctrl+Alt+N** ouvre Notes. **Ctrl+S** enregistre immédiatement.
